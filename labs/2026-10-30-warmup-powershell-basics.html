Lab 08: Warm-up - PowerShell Basics

Warm-upPowerShellHelp Desk⏱ 10–15 min

Safe practice: Use your own Windows computer or a disposable lab VM. These commands only inspect information and create a small file in your temporary folder; do not run practice commands on a production server.

Skill & Scenario

A teammate asks you to gather a few PC facts and save a short note. Practice moving around PowerShell, getting help, and selecting useful command output without changing system settings.

Time Estimate

10–15 minutes.

Prerequisites

  • Windows 10 or 11 with Windows PowerShell or PowerShell 7.
  • No administrator rights or extra modules are needed.

Steps

Get-Location
Get-ChildItem | Select-Object -First 5 Name, Length

Expect a folder path followed by up to five names and file sizes.

Get-Help Get-ChildItem -Examples

If local help is not installed, PowerShell will say so; the command itself is still safe.

$computer = $env:COMPUTERNAME
$os = Get-CimInstance Win32_OperatingSystem
$os | Select-Object CSName, Caption, BuildNumber
"Computer: $computer"

Expect your computer name and Windows edition/build. Select-Object keeps the output focused.

$note = Join-Path $env:TEMP 'lab08-note.txt'
"$computer runs $($os.Caption)" | Set-Content $note
Get-Content $note

Expect one line describing your computer. The file stays in your temporary folder until cleanup.

Verify it worked

  • Get-Location showed your current folder.
  • The selected computer and operating-system details appeared.
  • Get-Content $note displayed the line you saved.

Cleanup / rollback

Remove only the note created by this exercise; the command succeeds even if you already removed it:

Remove-Item -LiteralPath $note -ErrorAction SilentlyContinue

Why this matters on the job

Support staff use PowerShell to gather evidence quickly, narrow noisy output to the fields that matter, and record findings without making unnecessary changes.

Interview questions

Why use Select-Object when gathering system information?

It keeps output focused on the properties needed for the ticket, making results easier to read and share.

How can you learn the parameters for an unfamiliar PowerShell command?

Use Get-Help with the command name, and use its examples to see common patterns.
