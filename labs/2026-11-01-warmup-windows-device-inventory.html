Lab 10: Warm-up - Windows Device and Network Inventory

Warm-upWindowsNetworkingPowerShell⏱ 10–15 min

Safe practice: Use a Windows lab VM or your own device. The commands below only read local settings; do not reset adapters, change IP settings, or run these checks on a device you are not authorized to inspect.

Skill & Scenario

A user says their laptop cannot reach a work resource. Practice collecting basic device and network facts first, before attempting a fix or escalating.

Time Estimate

10–15 minutes.

Prerequisites

  • Windows 10 or 11.
  • Windows PowerShell or PowerShell 7; administrator rights are not required.

Steps

$os = Get-CimInstance Win32_OperatingSystem
$computer = Get-CimInstance Win32_ComputerSystem
$os | Select-Object CSName, Caption, Version, BuildNumber
$computer | Select-Object Manufacturer, Model

Expect the device name, operating-system version, manufacturer, and model.

Get-NetAdapter |
  Select-Object Name, InterfaceDescription, Status, LinkSpeed

Expect one row per adapter. A disconnected adapter may show Disconnected; that is evidence, not a reason to change settings.

Get-NetIPConfiguration |
  Select-Object InterfaceAlias, IPv4Address, IPv4DefaultGateway, DNSServer

Compare the interface alias with the adapter status. An address or gateway may be absent when that interface is disconnected.

ipconfig /all

Find the same adapter name, IPv4 address, default gateway, and DNS servers in the detailed output.

Verify it worked

  • You recorded a device name and Windows build.
  • You can identify the active adapter and its connection status.
  • You can find the IPv4 address, default gateway, and DNS entries, or note which are missing.

Cleanup / rollback

No cleanup is needed: these commands only display configuration and do not modify network settings.

Why this matters on the job

Capturing the device identity and current network configuration gives the next technician actionable evidence and helps avoid risky changes based on guesses.

Prepares you for

Interview questions

Why record network settings before changing them?

A baseline helps isolate the cause, supports rollback, and gives other technicians useful evidence.

What might it mean if an interface has no IPv4 gateway?

The adapter may be disconnected, or the network may not have supplied a gateway; check connection context before changing settings.
