Build a Help Desk “PC Info” Tool in PowerShell

Track: PowerShell · Builds on Lab 04 (same Windows 11 eval VM; turns your triage checks into a reusable function)
⏱ 25–30 min Level: Entry+ Skill: CIM queries, functions, parameters, pipeline, try/catch, CSV export

The ticket

REQ-0074 · Priority: P4 (internal)
From: Dana (IT Lead) <dana@contoso.lab>
“Every time someone calls in, Tier 1 spends five minutes clicking around to find the hostname, OS build, uptime, free disk, IP, and who's logged in. Can you write us one command that grabs all of that, works on more than one PC, and doesn't blow up when a machine is offline?”

This is how junior admins get noticed: you take a manual checklist (like yesterday's slow-PC triage) and turn it into a tool the whole desk can use. You'll build an advanced function, Get-PCInfo, that returns clean objects, accepts pipeline input, handles failures gracefully, and exports to CSV.

  • Windows PowerShell 5.1 (built in) or free PowerShell 7. Free VS Code with the PowerShell extension is nice, but Notepad works.
  • Optional: your Lab 01 Windows Server eval DC running, if you want to test against a second machine.

Steps

Open PowerShell as admin in the VM. RemoteSigned lets your own local scripts run while still blocking unsigned downloaded ones.

Before writing a tool, find where each fact lives. CIM (the modern replacement for Get-WmiObject) is your best friend here.

Get-CimInstance Win32_OperatingSystem | Select-Object CSName, Caption, BuildNumber, LastBootUpTime
Get-CimInstance Win32_ComputerSystem  | Select-Object Manufacturer, Model, UserName, TotalPhysicalMemory
Get-CimInstance Win32_LogicalDisk -Filter "DeviceID='C:'" | Select-Object DeviceID, Size, FreeSpace
Get-CimInstance Win32_NetworkAdapterConfiguration -Filter "IPEnabled=True" | Select-Object Description, IPAddress, DNSServerSearchOrder

Notice sizes are in raw bytes and IPAddress is an array. You'll clean both up.

Save this as C:\Lab05\PCInfo.ps1 (notepad C:\Lab05\PCInfo.ps1). Read it before you run it: every line is something you could be asked about.

function Get-PCInfo {
    <#
    .SYNOPSIS
        Tier 1 snapshot: hostname, OS, uptime, disk, RAM, IP, logged-on user.
    .EXAMPLE
        Get-PCInfo -ComputerName localhost, PC-404
    #>
    [CmdletBinding()]
    param(
        [Parameter(ValueFromPipeline, ValueFromPipelineByPropertyName)]
        [Alias('Name','CN')]
        [string[]]$ComputerName = $env:COMPUTERNAME
    )
    process {
        foreach ($pc in $ComputerName) {
            Write-Verbose "Querying $pc"
            try {
                $session = New-CimSession -ComputerName $pc -ErrorAction Stop
                $os   = Get-CimInstance -CimSession $session Win32_OperatingSystem -ErrorAction Stop
                $cs   = Get-CimInstance -CimSession $session Win32_ComputerSystem -ErrorAction Stop
                $disk = Get-CimInstance -CimSession $session Win32_LogicalDisk -Filter "DeviceID='C:'"
                $net  = Get-CimInstance -CimSession $session Win32_NetworkAdapterConfiguration -Filter "IPEnabled=True"
                $up   = (Get-Date) - $os.LastBootUpTime

                [PSCustomObject]@{
                    ComputerName = $os.CSName
                    Status       = 'Online'
                    OS           = $os.Caption
                    Build        = $os.BuildNumber
                    UptimeDays   = [math]::Round($up.TotalDays, 1)
                    CFreeGB      = [math]::Round($disk.FreeSpace / 1GB, 1)
                    CFreePct     = [math]::Round(($disk.FreeSpace / $disk.Size) * 100, 0)
                    RAMGB        = [math]::Round($cs.TotalPhysicalMemory / 1GB, 1)
                    IPv4         = ($net.IPAddress | Where-Object { $_ -match '^\d+\.' }) -join ', '
                    LoggedOnUser = $cs.UserName
                }
                Remove-CimSession $session
            }
            catch {
                [PSCustomObject]@{
                    ComputerName = $pc
                    Status       = "Failed: $($_.Exception.Message.Split([Environment]::NewLine)[0])"
                    OS = $null; Build = $null; UptimeDays = $null; CFreeGB = $null
                    CFreePct = $null; RAMGB = $null; IPv4 = $null; LoggedOnUser = $null
                }
            }
        }
    }
}

Dot-sourcing (the leading . ) loads the function into your current session.

Get-Help Get-PCInfo -Examples

A good tool reports a failure as data instead of stopping the whole run. PC-404 doesn't exist; it should come back as a Failed row while localhost still succeeds.

Get-PCInfo -ComputerName localhost, PC-404 | Format-Table ComputerName, Status, UptimeDays, CFreePct

Now see why -ErrorAction Stop matters: temporarily delete it from the New-CimSession line, re-dot-source, and run again. The error prints in red, but catch never fires because the error was non-terminating. Put it back.

This is how Tier 1 would actually use it: a list of machines from a ticket or an AD query.

"localhost`n$env:COMPUTERNAME`nPC-404" | Set-Content C:\Lab05\pcs.txt
Get-Content C:\Lab05\pcs.txt | Get-PCInfo | Format-Table -AutoSize

# Only show machines that need attention
Get-Content C:\Lab05\pcs.txt | Get-PCInfo |
    Where-Object { $_.Status -ne 'Online' -or $_.CFreePct -lt 20 -or $_.UptimeDays -gt 14 }

If your Lab 01 DC is up and the VM is domain-joined, also try Get-ADComputer -Filter * | Get-PCInfo. That's what ValueFromPipelineByPropertyName plus the Name alias buys you.

$stamp = Get-Date -Format 'yyyy-MM-dd_HHmm'
Get-Content C:\Lab05\pcs.txt | Get-PCInfo |
    Export-Csv -Path "C:\Lab05\PCInfo_$stamp.csv" -NoTypeInformation
Import-Csv "C:\Lab05\PCInfo_$stamp.csv" | Format-Table

Interview questions

  1. Why should a PowerShell function output objects instead of formatted text? (Objects can be piped to Where-Object, Sort-Object, Export-Csv, and other commands. Format-Table output is display-only, so you put formatting last, if at all.)
  2. What's the difference between a terminating and non-terminating error, and how does that affect try/catch? (Non-terminating errors write to the error stream and keep going, so catch never sees them. Adding -ErrorAction Stop, or setting $ErrorActionPreference, turns them into terminating errors that catch can handle.)
  3. Get-WmiObject vs Get-CimInstance: which would you use and why? (Get-CimInstance. It uses WS-Man by default, works through firewalls that allow WinRM, supports reusable CIM sessions, and works in PowerShell 7. Get-WmiObject uses DCOM and was removed in PowerShell 7.)
